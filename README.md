# Контур ВПН — NetworkChecker V2 (.NET 10 / Avalonia 12)

Автономное Windows-приложение для аудита ВПН-конфигов, подписок, DNS-маршрутизации, ТСПУ-блокировок и перебора SNI (`Directory.Build.props`, `.editorconfig`, `build.ps1`, `TreatWarningsAsErrors=true`).

## Быстрый старт (Windows 10/11)

1. Распакуйте архив в папку проекта (например `D:\Projects\NetworkChecker-V2`).
2. Откройте **`NetworkChecker.slnx`** в Visual Studio 2022/2026 или Rider и нажмите **F5** — либо соберите готовый `.exe` из PowerShell:

```powershell
# Сборка без кэша + прогон всех модульных тестов xUnit
./build.ps1

# Публикация одного файла artifacts/win-x64/NetworkChecker.exe
./build.ps1 -Publish

# Автономный .exe без требования установленного .NET 10 на ПК
./build.ps1 -Publish -SelfContained
```

## Что включено в главное окно (5 вкладок)

1. **Проверка ВПН и подписки** — автозагрузка HTTPS-подписок и разбор JSON-массивов Happ/Xray, `vless://` (XHTTP / TCP Vision / WS), `hy2://`, AmneziaWG (`.conf`), полная карточка подписки, проверка всех узлов одним кликом, «автолечение», точечная врезка Ninja DNS, извлечение одного узла в буфер, локальная ссылка подписки (`127.0.0.1`) и экспорт в файл.
2. **Защита DNS (DNS-архитектор)** — приватные No-Log профили (`Ninja Privacy: Njalla + LibreDNS`, `Mullvad + Quad9`, `Comss + AdGuard`, `Cloudflare + Google`), режим «Только блок DNS» и «Полный блок + Routing», объяснение роли `localhost` и сплит-правила `77.88.8.8` для `geosite:category-ru`, а также точечная врезка блока `dns` в конфиг/подписку без затрагивания нижних секций.
3. **Отпечатки ТСПУ** — локальное сканирование провайдера с вашего ПК: проверка «Белых списков» (Яндекс/ВК/Госуслуги/Ozon против глобальных узлов), ступенчатая отсечка потока 16 КБ (4 → 16 → 64 → 512 КБ), детект L7 SNI и TLS ECH.
4. **Стек Windows и перебор SNI** — нативный аудит сетевого стека ОС (Wintun/TUN, MTU, утечки DNS через SMHNR, глобальные маршруты IPv6, порты `10808/10809/2080/7890`) + комбинированный перебор SNI (из текущей подписки + база белых доменов РФ/CDN + соседи подсети `/24`) с врезкой лучшего SNI в конфиг одним кликом.
5. **Заявка в техподдержку** — 2-шаговый сбор срезов «Без ВПН (РФ-провайдер)» и «С ВПН (туннель)» с замером скорости, авто-маскировкой домашнего IP/UUID, копированием текста для Telegram-бота и сохранением `.md`-отчёта.
